#Alô Mãe 
</br>
Acompanhe a entrada e saída do seu filho em tempo real
</hr>
Estou desenvolvendo um aplicativo chamado "Alô mãe" – um sistema de controle de acesso escolar com notificações em tempo real para pais, professores e instituições. O app usa Next.js (frontend) e Firebase (Auth + Firestore) como backend. Preciso de ajuda para definir as regras de negócio, permissões e operações CRUD para cada tipo de usuário no Firestore, incluindo as regras de segurança (Firebase Security Rules). Também preciso de uma estrutura de dados clara para as coleções.
